The goal chain

G1 · bootstrap
Project scaffold + emulator boot
Spin up an empty Compose Android project. Build it. Install it on the headless emulator. Verify it launches.
condition:
  ./gradlew :app:assembleDebug exits 0,
  adb install -r app/build/outputs/apk/debug/app-debug.apk succeeds,
  adb shell am start -n com.ptc.launcher/.MainActivity launches,
  adb shell dumpsys activity activities | grep "mResumedActivity.*com.ptc.launcher" matches.
  Stop after 30 turns.
G2 · home claim
Launcher claims default home + four-direction picker
Declare intent-filters as a launcher app. Claim it on the emulator. Implement the post-unlock four-direction circle (80px / 60px threshold). Tapping each direction navigates to a stub destination.
condition:
  adb shell cmd package set-home-activity com.ptc.launcher/.MainActivity succeeds,
  pressing HOME from any app returns to the picker (verified via dumpsys),
  swipe-up/down/left/right gestures dispatch the correct navigation intent
  (verified by instrumentation test that simulates 4 swipes and asserts on
  the resulting activity for each). Stop after 40 turns.
G3 · four screens
Discover, Ask, Connect, Home destinations render
Compose screens for each direction. Discover: app tile grid with progress bars bound to per-app state. Ask: waveform + memory snippet placeholders. Connect: unified inbox list with mock conversations. Home: 4×4 grid from PackageManager.
condition:
  Compose UI tests pass for each screen,
  each screen renders without exception on the emulator,
  Discover screen shows at least 3 app tiles with progress bars,
  Connect screen shows at least 5 mock conversations with platform badges,
  Home screen lists at least 8 installed packages.
  Stop after 50 turns.
G4 · per-app grayscale
Grayscale ramp on foreground
AccessibilityService that watches foreground app changes. For each app with mode=grayscale, set system Color Correction (DALTONIZER_MODE → grayscale) interpolated linearly by timeSpentTodayMs / (dailyRampMinutes × 60000). Clear when app leaves foreground. 250ms tick. Daily reset at midnight via AlarmManager.
condition:
  enable_grayscale_service.sh succeeds (asks adb to grant
  WRITE_SECURE_SETTINGS + bind AccessibilityService),
  launching com.android.chrome triggers ACCESSIBILITY_DISPLAY_DALTONIZER
  setting flip from 0 to non-zero within 2 seconds,
  leaving chrome flips back to 0 within 2 seconds,
  per-app daily-counter increments visible in app's debug screen.
  Stop after 40 turns.
G5 · passive tracking
UsageStatsManager wired
Read usage stats since boot. Surface per-app time-today in the Discover tiles. No new visual, just real numbers.
condition:
  Discover screen replaces hardcoded progress values with
  UsageStatsManager-derived per-app durations,
  unit test confirms aggregation logic correctly bins by package and day.
  Stop after 25 turns.

Goals run sequentially. If one fails, the supervisor records the failure but continues to the next (no cascading abort — we want to see what gets done, not stop at the first hiccup). Each goal capped at the turn count above + a 90-minute wall clock.
