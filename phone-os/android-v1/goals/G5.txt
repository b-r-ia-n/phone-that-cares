DiscoverScreen replaces hardcoded `timeSpentTodayMs` values with values derived from `UsageStatsManager.queryUsageStats(INTERVAL_DAILY, ...)`. The mapping from UsageStats event records to per-package per-day duration is correct (only counts time between ACTIVITY_RESUMED and the next ACTIVITY_PAUSED for the same package; ignores stale events older than midnight in the device's current timezone). A unit test in `app/src/test/` exercises the aggregation logic with synthetic event lists and asserts correct durations for: a single ~30min session, two interleaved sessions of two packages, a session that crosses midnight (only post-midnight counted), and an unclosed session (duration up to now). All assertions pass via `./gradlew :app:testDebugUnitTest`. Stop after 25 turns.
