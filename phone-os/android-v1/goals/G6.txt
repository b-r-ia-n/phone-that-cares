AskScreen wires up real STT and Argos round-trip. Tapping the microphone affordance starts AudioRecord at 16kHz mono, captures until the user taps again or 30s elapses. The captured audio is POSTed to OpenAI Whisper API at https://api.openai.com/v1/audio/transcriptions using the OPENAI_API_KEY env var (read from a BuildConfig field that the build script reads from env). The transcribed text appears in the screen as the user-utterance bubble. That text is then POSTed to the Argos backend (val.town webhook URL — read from BuildConfig.ARGOS_WEBHOOK_URL; if empty, mock the response with a stub). The Argos text response renders below the user-utterance bubble. An emulator test that injects a known WAV file as the audio source (via `adb push` + a stub AudioRecord shim) and verifies the rendered transcription text. If OPENAI_API_KEY is not set in the environment at build time, the test asserts the UI shows a clear "STT not configured" message and gracefully degrades. Stop after 35 turns.
