An AccessibilityService named GrayscaleService is declared in AndroidManifest with TYPE_WINDOW_STATE_CHANGED, runs on the emulator, and watches foreground app changes. For any package configured with mode=GRAYSCALE in the per-app state store, the service writes to Settings.Secure.ACCESSIBILITY_DISPLAY_DALTONIZER_ENABLED=1 and ACCESSIBILITY_DISPLAY_DALTONIZER=0 (grayscale mode) when that package becomes foreground. The intensity is gated by a 250ms tick that recomputes progress = min(1.0, timeSpentTodayMs / (dailyRampMinutes * 60_000)) and the matrix is applied. When the package leaves foreground, daltonizer is reset to disabled. Setup script `harness/enable-accessibility.sh` exists and uses `adb shell pm grant com.ptc.launcher android.permission.WRITE_SECURE_SETTINGS` and `adb shell settings put secure enabled_accessibility_services com.ptc.launcher/.GrayscaleService`. A test script `harness/test-grayscale.sh` launches `com.android.chrome`, waits 2s, reads `adb shell settings get secure accessibility_display_daltonizer_enabled`, expects 1; presses HOME, waits 2s, re-reads, expects 0. Both branches of the test pass. Stop after 40 turns.
