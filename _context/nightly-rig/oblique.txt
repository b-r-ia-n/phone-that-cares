# Oblique deck — method cards for the nightly rig.
# Curated/adapted in the spirit of Eno & Schmidt's "Oblique Strategies,"
# with a few PTC-tuned additions. One card per non-comment line.
# The wrapper picks one per night by date-hash. Sit with it; honor it if you can;
# set it aside if it would hurt the work — but log one line on how it was used.
