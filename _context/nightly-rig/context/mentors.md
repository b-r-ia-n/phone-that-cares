# Mentors

## About This File

This file serves as an index of mentors. Detailed information about each mentor can live in a separate knowledge base (e.g., Obsidian vault, markdown files, etc.).

Types:
- **Real Life**: People you know personally
- **Public Figure**: Living people you don't know personally but learn from
- **Historical**: People no longer alive
- **Imaginal**: Fictional characters, archetypes, or composite figures


## Santiago Calatrava / The Wright Brothers

- **Type**: Public Figure
- **Areas**: Architecture, art, engineering/ aviation, persistence
- **Notes**: Spanish architect. Admired for willingness and ability to go very deep on technical subjects to further his art. That tension/balance/synergy between technical depth and artistic expression is something Brian finds beautiful and cares about.

## Robert Caro

- **Type**: Public Figure
- **Areas**: Writing, power, impartiality
- **Notes**: Far and away favorite author. Series on Lyndon Johnson and how power works in American-style democracy. A model for impartiality — seeing clearly without collapsing into judgment or worship.
