*2026-04-26 · v0 (50 unfiltered) · for Brian to downsample*

## Tag legend (rough — feel free to ignore)

- **define** — what is the agent, who is it
- **body** — agent x your physical state
- **mundane** — agent x daily life
- **time** — agent across hours/days/years
- **inversion** — flip it
- **creature** — agent as animal/object
- **other** — agent x people not you
- **family** — agent x parents, dad, mom
- **refusal** — what it doesn't do
- **small** — limit-its-scope prompts
- **joke** — playful entry points
- **hard** — heavier, session 2 territory
- **money** — cost / who pays

## Notes for downsampling

The "easy and feel-good" goal of Session 1 maps best to: define / mundane / creature / joke / small. (Specifically: 1, 2, 5, 7, 15, 22, 25, 29, 30, 32, 36, 37, 38, 43, 44.)

The "user needs and how the agent navigates the current world" cluster maps best to: body / mundane / refusal / hard / family. (Specifically: 4, 14, 21, 23, 24, 34, 39, 40, 41, 42, 46, 47.)
